# Adoption guide

## 1. Select a deployment profile

Identify whether the implementation is prompt-only, agent-runtime, multi-agent, memory-enabled, safety-critical, offline-first, or human-review assisted.

## 2. Define the authoritative record

Document source precedence, immutable transcript access, correction-ledger authority, memory status, and conflict resolution.

## 3. Implement the semantic boundary

Provide a governed `SemanticJudge` with structured output, evidence references, uncertainty support, and escalation behavior.

## 4. Implement mechanical controls

Implement legal state transitions, response gating, audit records, correction integration, memory gating, and safety concurrency.

## 5. Run conformance

Execute all mandatory cases for the claimed standard version. Add domain-specific, multilingual, long-context, and adversarial cases.

## 6. Publish the claim precisely

State the exact standard version, implementation version, semantic-judge profile, conformance-suite version, date, and known limitations.

Do not represent a partial diagnostic pass as full conformance.
